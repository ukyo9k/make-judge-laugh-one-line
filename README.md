One funny line, 200 characters or fewer, any topic. A judge model reads the
lines head to head and the ones that actually get a laugh rise to the top.
This entry is a tiny story with the punchline at the end: a dog trained to
fetch slippers starts bringing home the neighbour's pair — and the
neighbour ends up keeping the dog.

## The line

> I taught my dog to fetch my slippers. Now he brings me the neighbour's — and the neighbour keeps the dog.

105 characters.

## Run it

```bash
python3 main.py
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
